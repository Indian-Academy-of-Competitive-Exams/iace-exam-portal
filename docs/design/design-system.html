The red decision — brand vs. danger
Red is the brand, so it can't also mean "danger." Resolution: primary red = go / confirm / brand only · Cancel = neutral grey (a dismissal, never red) · Destructive (delete / reject / un-approve) = a distinct cooler crimson, always with an icon + confirm.

v0.1 used a flat 1.5 everywhere. Telugu matras clip at 1.5, so :lang(te) gets 1.8 from the stylesheet — tag the element, don't branch in JS. The Indic faces sit after the Latin ones in --font-sans so the browser resolves per-glyph; system-ui alone does not reliably cover Telugu.

Negative tracking used to be on every heading including 16 px, where it does nothing but cramp. Banded so it can only be applied where it actually helps.

Exam question palette — faithful to the real CBT (fixed convention)
Answered Not answered Not visited Marked for review Answered & marked Current question
Five states, not four. Answered & marked (cell 6 — purple body, green tick) is the one candidates lean on hardest in the last ten minutes: it says "I have put something down, but come back to it." A palette that collapses it into plain marked loses the difference between a question with an answer banked and one with nothing. Cell 7 carries the current-question ring, which is positional and stacks on top of any state — it is deliberately blue so it can never be read as answered, marked, or wrong.
Shape carries the meaning alongside colour — square answered, pentagon not-answered, circle marked — so the palette survives colourblindness. These colours follow the real government-exam convention and live only inside the CBT screen; they are intentionally separate from the app's brand semantics.
Timer — the highest-stakes component in the product
01:47:22 normal · outlined
00:04:31 warning · tinted · ≤ 5:00
00:00:38 critical · filled + pulse · ≤ 1:00
00:38 .timer--sm · mobile header
Escalation is by form — outlined, then tinted, then filled — not by hue. Red is deliberately unused: it already means brand and it already means destructive, and a third meaning on the element with the most attention on it would collapse all three. A filled block replacing an outlined one is also a stronger peripheral signal than a hue shift, and it survives colourblindness.
Three things are non-negotiable: tabular figures + a fixed min-width so the clock never reflows the header as digits change; aria-live="off" on the ticking value, or a screen reader announces every second; and the pulse is decorative only — the state is carried by colour and by the number itself, never by the animation.

Every empty state carries exactly three things: what is missing, why, and the one action that fixes it. Never ship one without a primary action. The error variant reuses the same frame — errors say what happened and how to recover; they do not apologise and they are never vague.

Ships as React — dialog.tsx, on Radix, with ConfirmDialog for the destructive case on the right. There is no .modal class any more: the CSS that used to be here could not trap focus, and an untrapped modal is worse than no modal — the reader tabs behind it into a page they cannot see. What you see below is a stand-in drawn to match; the TSX is the truth, and it reads the same --modal-* tokens. Shown inline so the page still scrolls. Never make the destructive action the default-focused button: Cancel is neutral grey and takes the focus, delete is crimson and has to be aimed at. ConfirmDialog does that itself.
Toast · Tooltip · Pagination — these ship as React
These three have no class in components.css by design. They are toast.tsx, tooltip.tsx and pagination.tsx, already token-driven through the Tailwind preset. A raw CSS copy alongside them would be a second, differently-shaped design of the same thing — and the one nobody renders is the one that rots. Always name the properties. A bare transition:.12s animates layout too, which is how a table starts sliding on hover — --transition-colors exists so nobody writes that. prefers-reduced-motion is honoured globally: a candidate with vestibular sensitivity should not be fighting transitions during a timed exam.
Focus & disabled
Focused Invalid Disabled
Focus is defined once, on :focus-visible, so mouse users never see it and keyboard users always do. Disabled is its own three tokens, not opacity:.5 — that dragged label text to about 2.3:1 and failed WCAG.
